# REVERSE DUNGEON : SPARTA

> 마왕이 되어 던전을 지키는 역전된 던전 RPG 게임

## 📖 프로젝트 소개

전통적인 던전 게임과 달리, 플레이어가 마왕이 되어 자신의 던전으로 침입하는 모험가들을 막아내는 콘솔 기반 턴제 RPG 게임입니다.

### 🎮 게임 특징

- **역전된 관점**: 마왕의 시점에서 던전을 지키는 새로운 경험
- **완전한 RPG 시스템**: 레벨업, 스킬, 장비, 아이템 합성 등
- **턴제 전투**: 속도 기반 턴 순서와 다양한 스킬 시스템
- **몰입감 있는 사운드**: BGM과 효과음으로 게임 경험 향상

## 🛠️ 기술 스택

- **언어**: C# (.NET 8.0)
- **플랫폼**: Windows Console Application
- **라이브러리**: 
  - NAudio (오디오 재생)
  - NPOI (데이터 처리)

## 🎯 주요 기능

### 전투 시스템
- 속도 기반 턴제 전투
- 물리/마법/버프 스킬 시스템
- 버프/디버프 효과와 지속시간 관리

### 캐릭터 시스템
- 레벨업과 능력치 성장
- 5가지 몬스터 직업군 (전사, 도적, 마법사, 힐러, 궁수)
- 동적 난이도 조절

### 아이템 시스템
- 6종류 장비 아이템 (갑옷, 무기, 헬멧, 신발, 반지, 목걸이)
- HP/MP 회복 소비 아이템
- 아이템 합성 시스템

### UI/UX
- 직관적인 키보드 조작 (화살표키, 엔터, ESC)
- 스크롤 가능한 메뉴 시스템
- 컬러 텍스트와 ASCII 아트

## 🎲 게임플레이

### 조작법
- **화살표 키**: 메뉴 선택
- **Enter**: 선택 확인
- **C**: 취소/뒤로가기

### 게임 진행
1. 마왕 캐릭터 생성 및 스토리 시작
2. 던전 20층을 내려가며 모험가들과 전투
3. 승리 시 보상 획득, 패배 시 게임오버
4. 최종 목표: 모든 층을 클리어하고 엔딩 선택

## 📁 프로젝트 구조

```
ReverseDungeonSparta/
├── Core/
│   ├── GameManager.cs          # 게임 전체 흐름 관리
│   ├── BattleManager.cs        # 전투 시스템 관리
│   └── TurnManager.cs          # 턴 순서 관리
├── Characters/
│   ├── Character.cs            # 캐릭터 기본 클래스
│   ├── Player.cs              # 플레이어(마왕) 클래스
│   └── Monster.cs             # 몬스터 클래스
├── Items/
│   ├── Item.cs                # 아이템 기본 클래스
│   ├── EquipItem.cs           # 장비 아이템
│   └── UsableItem.cs          # 소비 아이템
├── Systems/
│   ├── Skill.cs               # 스킬 시스템
│   ├── Buffer.cs              # 버프/디버프 시스템
│   └── ComputeManager.cs      # 확률 계산
├── Managers/
│   ├── AudioManager.cs        # 사운드 관리
│   ├── ViewManager.cs         # UI 출력 관리
│   └── InventoryViewManager.cs # 인벤토리 UI
└── Utils/
    ├── Util.cs               # 유틸리티 함수
    └── DataBase.cs           # 게임 데이터
```

## 🚀 실행 방법

### 요구사항
- Windows 10 이상
- .NET 8.0 Runtime

### 설치 및 실행
1. 프로젝트 클론
```bash
git clone [repository-url]
cd ReverseDungeonSparta
```

2. 빌드 및 실행
```bash
dotnet build
dotnet run
```
